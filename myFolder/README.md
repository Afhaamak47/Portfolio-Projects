Working Hours Dashboard
Project Overview

This is an interactive MIS dashboard designed to track employee attendance and productivity. It automates reporting, reduces manual errors, and provides actionable insights for management.

Data Cleaning & Preparation

Corrected date column formats for consistency.

Removed unnecessary/waste columns to simplify the dataset.

Handled duplicates to ensure accurate reporting.

Used VLOOKUP to merge or fetch relevant data.

Applied PROPER function to clean text formatting.

Key Features

Attendance Tracking: Daily attendance and working hours monitoring.

Automated Reporting: VBA macros reduce manual effort and errors.

Actionable Insights: Highlights trends to help management improve productivity.

Tools Used

Excel: PivotTables, Charts, Conditional Formatting, VLOOKUP, PROPER

VBA: Automation for report generation and error checking

Usage

Open the Excel dashboard file.

Enable macros for automation.

Update dataset and explore dashboard metrics.
